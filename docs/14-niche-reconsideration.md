# 14. ニッチ再考 — カップルコンテンツは「低コスト高収益」か

docs/03 で決めた「2D アニメ・カップルあるある」を、**収益効率 (revenue per credit)** の観点でゼロベース再評価する。結論を先に: カップルあるあるは「ブランド資産型」であって「低コスト高収益型」ではない。低コスト高収益を最優先するなら、**ナレーション型ナレッジ/ストーリーコンテンツへの転換が数字上は圧倒的に優位**。

> コスト数値は本リポジトリでの Higgsfield 実測 (preflight/課金ログ)。RPM は 2026-07 時点の目安。

---

## 1. 現行路線の問題点 (数字で)

### 1.1 コスト構造: 「全秒キャラ動画」が高すぎる

カップルあるあるは**全カットがキャラクター動画生成** (Seedance 2.0: 22.5 credits/5s) を要求する。

| フォーマット | 実測ベース内訳 | 合計 |
| ------------ | -------------- | ---- |
| カップル動画 30s (現行) | 動画 22.5cr × 6ショット + 画像少々 | **~135 credits** |
| カップル動画 60s (TikTok CRP 対応版) | 同 ×12 | **~270 credits** |
| **ナレーション型 60s (静止画 + TTS)** | 静止画 0.12〜2cr × 8枚 + TTS ~5cr (実測: 100語=3.5cr) + explainer_video 組立 **無料** + 字幕 ~0.5cr | **~7〜15 credits** |

→ **同じ 60 秒で 20〜40 倍のコスト差**。残 791 credits で作れる本数: カップル動画 **5-6本** vs ナレーション型 **60-100本**。

### 1.2 収益構造: エンタメは RPM 最底辺

広告単価は「視聴者の購買意図」で決まる。コメディ視聴者には購買文脈がない。

| コンテンツ分類 | Shorts RPM | 長尺 RPM | アフィリエイト適性 |
| -------------- | ---------- | -------- | ------------------ |
| コメディ/エンタメ (現行) | $0.05〜0.15 | $1〜4 | 弱 (文脈がない) |
| 金融・マネー系 | $0.15〜0.30 | **$8〜25** | **最強 (CPA $50-100/件の証券・カード案件)** |
| ビジネス/起業 | $0.12〜0.25 | $6〜15 | 強 (SaaS・教材) |
| テック/AI | $0.10〜0.25 | $5〜15 | 強 (ツール系) |
| 心理学/自己啓発 | $0.10〜0.20 | $4〜10 | 中 (書籍・アプリ) |
| 歴史/実話ドキュメンタリー | $0.08〜0.18 | $4〜10 | 中弱 |

### 1.3 revenue per credit (本質の指標)

長尺 10 分換算で比較 (docs/13 §7 のコンピレーション戦略込み):

| 路線 | 10分あたり制作コスト | 10分×10万再生の広告収益 | **収益/credit** |
| ---- | -------------------- | ----------------------- | --------------- |
| カップルアニメ (コンピレーション) | ~0 (Shorts 流用) だが元 Shorts が 135cr×12本 = 1,620cr | RPM $3 → $300 | $0.19/cr |
| **マネー系ナレーション (直接長尺)** | 静止画40枚 + TTS 1,500語 ≈ **100cr** | RPM $12 → $1,200 | **$12/cr** |

→ **credit あたり収益で ~60 倍の差**。「低コスト高収益」の答えは構造的にナレーション型ナレッジ側にある。

### 1.4 その他の構造問題

- **コメディは AI の最弱分野**: 笑いのタイミング・間・オチの質が命で、スベった瞬間に維持率ゼロ。ナレッジ系は「情報の面白さ」が主役で、Claude のリサーチ・構成力 (=我々の最強資産) がそのまま品質になる
- **TikTok CRP の 1分縛り** (docs/12 §2.3): カップル動画の 60s 化はコスト倍増だが、ナレーション型は元々 60-90s が自然な尺 → 追加コストなしで CRP 対象
- **多言語展開**: ナレーション型は dubbing との相性が最良 (口パク同期不要、音声差し替えのみ)

## 2. 現行路線に残る強み (公平に)

| 強み | 評価 |
| ---- | ---- |
| キャラ IP (グッズ・案件・ライセンス = docs/12 M3/M4) | 本物。ただし収益化は 5万フォロワー以降の話 |
| シェアループ (「これ私たちじゃん」) | 成長は速いが、成長≠収益 (RPM が低いまま) |
| 差別化・ブランド性 | AI 量産スロップ判定に対する防御としては優秀 |
| YMYL リスクなし | ナレッジ系 (特に金融) は誤情報・規約リスクを背負う |

→ カップル路線は「時間をかけて IP を育て、案件とグッズで回収する」**ブランド投資型**。「低コスト高収益」という今回の目的関数とはズレている。

## 3. 候補ニッチ比較 (低コスト×高収益×我々の資産適合)

評価軸: RPM / 制作コスト / Claude 適合 (脚本・リサーチで勝てるか) / 飽和度 / ポリシーリスク。◎=3 ○=2 △=1 ✕=0

| ニッチ | RPM | コスト | Claude適合 | 飽和度(低いほど◎) | リスク低さ | 計 |
| ------ | --- | ------ | ---------- | ------------------ | ---------- | -- |
| **A. マネー実話 (詐欺・大失敗・大逆転の物語)** | ◎ | ◎ | ◎ | △ | ○ | **13** |
| B. 心理学/人間行動の意外な事実 | ○ | ◎ | ◎ | △ | ○ | 11 |
| C. 歴史/実話ミステリー・ミニドキュメンタリー | ○ | ◎ | ◎ | △ | ◎ | 12 |
| D. AI/テックニュース解説 | ◎ | ◎ | ○ | ○ | △ (鮮度依存・寿命短) | 11 |
| E. 純金融アドバイス (投資 how-to) | ◎ | ◎ | ○ | ✕ | ✕ (YMYL 直撃) | 8 |
| F. 現行カップルあるある | △ | ✕ | ○ | ○ | ○ | 8 |
| G. キッズ | △ | ○ | △ | ✕ | ✕ (COPPA) | 5 |

### 推奨: **A. マネー実話** (第2候補: C. 実話ミステリー)

**"The $X Story" 型 — 詐欺事件・企業の大失敗・億万長者の転落・宝くじのその後・世紀の取引** を 60-90s のナレーション付きビジュアルストーリーで。

- **RPM**: 金融広告主の単価が付く (長尺 $8-25) が、**「アドバイス」ではなく「物語」なので YMYL 直撃を回避** (E との決定的な違い)
- **リテンション**: 実話 + サスペンス構成 (「彼が気づいたとき、口座は空だった —」) はドキュメンタリー型の中で最も完視聴率が出る型
- **Claude 適合が最大**: 事件のリサーチ→サスペンス構成の脚本化はまさに LLM の主戦場。ネタ枯れしない (経済事件は無限に供給される)
- **アフィリエイト/案件**: マネー系オーディエンス → 証券口座 CPA、予算管理アプリ、ビジネス書。docs/12 M2/M3 の期待値が桁上がり
- **長尺化が本線**: 同テーマ 3 事件で 10-12 分ドキュメンタリー (100cr) — Shorts は完全にこの長尺への導線
- **飽和への回答**: この領域の既存 AI チャネルの大半は Wikipedia 表層の焼き直し。**一次資料 (裁判記録・SEC 文書・当時の報道) まで潜るリサーチ**と、Higgsfield の一貫したビジュアルスタイル (実写素材でなく統一トーンのシネマティック静止画) で差別化する

## 4. フォーマット設計 (低コスト構成の標準形)

```
60-90s Short (~10 credits):
  Claude: リサーチ + 150-200語の脚本 (Hook → 転落/転回 → 数字のパンチライン → 締めの一言)
  ↓
  nano_banana_pro / soul_2: シネマティック静止画 6-10枚 (統一グレーディング、事件の情景再現)
  ↓
  seed_audio TTS: ナレーション (実測 100語=3.5cr)。ドキュメンタリー調の男性低音 or 落ち着いた女性声で固定
  ↓
  explainer_video: 組立 (無料) + 焼き込み字幕 (0.05cr/block)
  ↓
  既存パイプライン: R2 → Postiz → 3チャネル (docs/07 がそのまま使える)
```

- 静止画に軽いズーム/パン (Ken Burns) を ffmpeg で付与 — 動画生成ゼロで「動き」を出す
- キャラ一貫性の代わりに**ビジュアルトーンの一貫性** (LUT・構図・タイポグラフィ) をチャネルの顔にする
- 週産可能本数: credits 制約が事実上消え、ボトルネックはレビューのみ → **週 5-7 本 + 月 2 本の長尺**が現実的

## 6. 選択肢まとめ

| 案 | 内容 | 向いている場合 |
| -- | ---- | -------------- |
| **A. 全面転換 (推奨)** | マネー実話ナレーション型へ。カップル資産は凍結 | 「低コスト高収益」を最優先するなら数字上これ一択 |
| B. 現状維持 | カップルあるある続行 | IP・ブランドを 1年以上かけて育てる覚悟がある場合 |
| C. ハイブリッド | 主力をナレッジ型に移し、カップルは週1の低頻度で継続 | 判断を保留したい場合。ただしリソース分散で両方中途半端になるリスク大 |

**A 採用時の初動**: (1) 新ニッチのベンチマーク調査 (docs/01 の再実施、5-10 チャネル)、(2) パイロット 3 本を ~30 credits で試作し完視聴率を実測、(3) docs/03 相当のコンテンツ戦略書き直し。パイロットが 60% 完視聴を切ったら C 案へ後退、という撤退ラインも先に決めておく。
