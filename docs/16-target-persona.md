# 16. ターゲットペルソナ詳細 — Weekly Money Briefing

docs/15 の番組編成が「誰の生活のどの時間に入り込むか」を定義する。docs/13 §2-3 (カップル路線の Emily ペルソナ) を**置き換える**ドキュメント。

設計原理: 広告収益は「視聴者の属性 × 購買意図」で決まる (docs/13 §2.1 の Tier 1 論理は続投)。金融コンテンツはさらに「**視聴者の金融行動そのもの**」が広告主 (証券・カード・家計アプリ) の標的なので、ペルソナ定義 = 収益定義になる。

---

## 1. 視聴者構成の想定 (金融系 YT の一般的分布に基づく)

| 軸 | 想定分布 | 含意 |
| -- | -------- | ---- |
| 性別 | **男性 70-75% / 女性 25-30%** | 金融系は構造的に男性偏重。ただし女性層は保存率・完視聴率が高く、家計系広告主の単価も高い — 「トレーダー向けノリ」を排し、排除しない設計にする (§5) |
| 年齢 | 25-34 が最厚 (~40%)、35-44 (~30%)、18-24 (~15%)、45+ (~15%) | コアは **25-44 の「資産形成期」** |
| 地域 | 🇺🇸 US 55-65% を目標、🇬🇧🇨🇦🇦🇺 15-20%、その他 20% | Tier 1 比率 60%+ が KPI (docs/13 §8 続投)。金融は Tier 1 とそれ以外の RPM 差が全ジャンル中最大 |
| 所得 | 世帯 $60k〜$150k 中心 | 「すでに富裕」ではなく「**資産形成中**」。この層が証券口座 CPA・家計アプリ広告の本丸 |

## 2. プライマリペルソナ — "Jake" (視聴の55%を想定)

> **Jake, 32歳男性。テキサス州オースティン在住、ソフトウェア企業のプロジェクトマネージャー。年収 $105k、婚約中。**
>
> - **資産**: 401(k) に給与の6% (会社マッチあり)、Fidelity の個人口座で S&P500 インデックス + 個別株3銘柄 ($40k)、Coinbase に BTC/ETH ($5k、2021年の高値掴みを未だ引きずる)、貯蓄 $25k (結婚式用)
> - **金融リテラシー**: 中級。「インデックス長期」が正解と知っているが、FOMC で市場がなぜ動くかは雰囲気でしか分かっていない。**分かっていないことを同僚に知られたくない**
> - **情報行動**: 朝トイレで Morning Brew (ニュースレター) を流し読み、通勤中はポッドキャスト、Reddit の r/personalfinance と r/stocks を ROM 専。Bloomberg は開かない (長い・専門的すぎる)
> - **視聴文脈**: **土曜朝、コーヒーを淹れながらの Shorts スクロール** (= Week in Money の投稿時刻)。日曜夜は翌週を漠然と考えて憂鬱になる時間 (= The Week Ahead)
> - **チャネルに求めるもの**: 「月曜の雑談で『CPI やばかったね』と言える状態」に90秒でしてくれること。**意見や煽りではなく、何が起きたかと、なぜか**
> - **嫌うもの**: 「この株を今すぐ買え」系、サムネの赤矢印と絶叫顔、ポジショントーク、20分の動画で結論を最後まで言わないやつ
> - **広告主から見た価値**: 証券口座乗り換え・ロボアド・高利回り貯蓄・クレカの最優良ターゲット

**Jake テスト** (制作判断基準): 「Jake は最後まで見て、月曜に同僚へ受け売りするか?」

## 3. セカンダリペルソナ2種

### "Priya" (25%) — 成長セグメント・未来のコア

> **Priya, 26歳女性。ロンドン在住、NHS の看護師からヘルステック企業に転職 2年目。年収 £38k。**
>
> - 昨年 ISA (英版 NISA) を開設し、毎月 £300 を全世界インデックスに積立開始。**投資歴 18ヶ月の初心者**
> - 「金利」「インフレ」が自分の家賃・積立にどう効くのかを知りたい。専門用語が2つ続くと離脱する
> - TikTok/Shorts が主情報源。金融系男性 YouTuber の「兄弟ノリ」が苦手でチャネルを探している
> - **刺さる枠**: Money Explained (用語解説) が入口 → 習慣化して週次に定着
> - 価値: 完視聴率・保存率が高くアルゴリズム評価に貢献。家計アプリ・積立サービス広告の標的。**英連邦圏 (UK/CA/AU) 比率の担い手**

### "Dave" (15%) — 高単価セグメント・長尺の主客

> **Dave, 51歳男性。オハイオ州在住、製造業の部門長。世帯年収 $160k、子供2人は大学生。**
>
> - 401(k) + IRA で $600k。**リタイアまで10-14年**、資産配分と金利動向が最大の関心事
> - Shorts はあまり見ない。**月次・四半期・年次の長尺レビューを TV (リビングの YouTube アプリ) で見る**
> - 価値: 視聴者数は少ないが **RPM への貢献が最大** (資産運用・保険・リタイアメント系広告の最高単価層)。長尺のミッドロール収益は実質この層が払っている
> - **刺さる枠**: Quarterly Review / Year in Review。Shorts からの導線ではなく検索・ブラウズ面から来る

## 4. アンチペルソナ (意図的に捨てる層)

| 層 | なぜ捨てるか |
| -- | ------------ |
| デイトレ・シグナル探し ("次に爆上げする銘柄は?") | 推奨を出さない方針 (docs/15 §5) と非互換。規約・法的リスクの源泉。離反も早い |
| 一攫千金系 (ミーム株・草コイン狙い) | 広告主品質を下げ、コメント欄を荒らす。アルゴリズムの視聴者プロファイルを汚染する |
| 金融プロ (機関投資家・アナリスト) | 90秒フォーマットに深さを求められても応えない。Bloomberg の領分 |

「捨てる」の実装: サムネ・タイトル・脚本から煽り語彙 (skyrocket, 🚀, "before it's too late") を禁止語に。**来てほしい層より、来てほしくない層を先にフィルタする**方が視聴者プロファイルは早く安定する。

## 5. 性別バランス設計 (25-30% の女性層を守る)

金融チャネルの多くが女性視聴者を「兄弟ノリ・トレード自慢・ジャーゴン」で無自覚に排除している。逆張りで:

- ナレーションは docs/15 §1 のドキュメンタリー調 (中立・落ち着き)。「俺は先週これ. で儲けた」的一人称トレード話法を構造的に排除 (そもそもナレーター = 無人格の定点観測)
- Money Explained は Priya 基準 (専門用語は必ず一文で定義)、Week in Money は Jake 基準 (テンポ優先)、と枠ごとに難易度を分離
- 生活接続の比喩を毎本1つ: 「金利0.5%上昇 = 平均的な住宅ローンで月$180増」— Jake にも Priya にも Dave にも自分ごと化する共通言語は**ドル換算の生活インパクト**

## 6. ペルソナ × 番組枠 × 収益のマッピング

| 枠 | 主客 | 視聴文脈 | 収益への役割 |
| -- | ---- | -------- | ------------ |
| Week in Money (土朝) | Jake | 週末朝のコーヒー・スクロール | 再生数・習慣形成 |
| The Week Ahead (日夜) | Jake | 日曜夜の「今週の段取り」時間 | 予告→回収ループの起点 |
| Money Explained (水昼) | Priya | 昼休み・通勤 | 新規流入の入口 (検索・おすすめ)、保存率 |
| Monthly Money Map | Jake + Dave | 週末のじっくり視聴 | ミッドロール収益の入口 |
| Quarterly / Year Review | **Dave** | リビング TV・大画面 | **RPM 最大化の本丸**。リタイアメント系広告 |

## 7. KPI への反映 (docs/13 §8 の改訂)

| 指標 | 目標 | 理由 |
| ---- | ---- | ---- |
| Tier 1 視聴比率 | 60%+ (据置) | RPM の土台 |
| 男女比 | 女性 25%+ を維持 | 25% を割ったら「トーンの男性ノリ化」が起きているサイン → 脚本トーン監査 |
| 視聴年齢 45+ 比率 | 長尺で 25%+ | Dave 層が長尺に付いているかの確認 |
| リピート視聴者比率 (YT Studio) | 90日で 30%+ | 定点観測は新規バズより**戻ってくる率**が本体 |
| TV デバイス視聴比率 (長尺) | 15%+ | Dave 層のリビング視聴の代理指標 |
