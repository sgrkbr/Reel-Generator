# 13. YouTube Shorts 完全攻略

docs/12 の M1 (プラットフォーム収益) のうち **YouTube Shorts を主戦場として深掘り** する。理由: (1) 収益プログラムに最初に到達しやすい、(2) TikTok と違いチャネルが**資産として蓄積**する (検索流入・登録者・長尺への転用)、(3) 収益の伸びしろ (長尺化・メンバーシップ) が最も大きい。

> 数値 (RPM・プログラム条件) は 2026-07 時点の目安。着手時に一次情報を再確認すること。

---

## 1. なぜ Shorts を主軸にするか — 3プラットフォームの役割再定義

| チャネル | 役割 | 理由 |
| -------- | ---- | ---- |
| **YouTube Shorts** | **収益の主軸・資産形成** | 登録者は減らない資産。Shorts→長尺→メンバーシップの拡張パスがある。RPM は低いが安定 |
| TikTok | 実験場・最速フィードバック | バズ判定が最速 (数時間)。勝ちネタの検証をここで行い、勝ったものが YT でも回る |
| IG Reels | 発見面・案件の名刺 | ブランド案件の商談は IG 経由が多い。収益は期待しない |

**運用原則: TikTok で検証 → 勝ちネタを YT に「本番投入」→ YT の蓄積が収益になる。**

## 2. ターゲット層の定義

### 2.1 地域: RPM ティアで優先順位を決める

Shorts の収益は「どの国の視聴者が見たか」で決まる。同じ100万再生でも収益は数倍違う。

| ティア | 国・地域 | Shorts RPM 目安 | 戦略 |
| ------ | -------- | --------------- | ---- |
| **Tier 1 (主標的)** | 🇺🇸 US, 🇨🇦 CA, 🇬🇧 UK, 🇦🇺 AU | $0.10〜0.25 | **全コンテンツ設計をここに合わせる** |
| Tier 2 | 🇩🇪 DE, 🇳🇱 NL, 北欧 | $0.08〜0.15 | 英語で自然に届く。追加施策不要 |
| Tier 3 | 🇮🇳 IN, 🇵🇭 PH, 🇮🇩 ID, 中南米 | $0.01〜0.05 | 再生数は稼げるが収益は薄い。**流入しすぎると平均 RPM が下がる**ので、ネタ選定で Tier 1 文化圏に寄せてフィルタする |

**Tier 1 に寄せる具体策** (アルゴリズムは「最初に反応した層に似た人」へ広げるため、初期の当て先が全て):

- ネタの生活文脈を Tier 1 に固定: Costco / streaming subscriptions / thermostat war / HOA / meal prep — 米国郊外〜都市部の生活語彙を使う (docs/03 のネタリストは既にこの方向)
- 字幕英語は US 綴り・US 口語 ("y'all" は南部過ぎるので避け、"literally" "lowkey" 程度の汎用スラングまで)
- 投稿時間を **US Eastern の夜 (19:00-22:00 ET)** に固定 → 初速の視聴者層を Tier 1 に誘導 (§5.2)
- 音声 (Wan 2.7 の口パク・モノローグ) は **General American アクセント** で統一

### 2.2 性別・年齢: コアは「25-40 の同棲・既婚層」、女性がエンジン

カップルあるあるコンテンツの視聴行動は非対称:

| セグメント | 割合目安 | 行動パターン | 設計への反映 |
| ---------- | -------- | ------------ | ------------ |
| **女性 25-40 (コア)** | 55-65% | **「これ私たちじゃん」とパートナーに共有する**。保存・シェア率が高い。夜のベッドスクロール時間帯に視聴 | シェアの起点。wife 視点の「あるある共感」を毎本必ず1つ入れる。オチで wife を負かさない (共感者を敵に回さない) |
| 男性 25-40 | 30-40% | 共有されて見に来る受動層 + husband モノローグに自分を重ねる能動層 | husband の内省モノローグ (docs/03 の差別化軸1) がこの層の登録動機。「言い返さないけど全部思ってる」が刺さる |
| 18-24 | 15-20% | 交際初期・同棲前。「将来こうなるのか」枠として消費 | メインターゲットにはしないが、普遍ネタ (texting in the same room 等) で自然に取れる |
| 45+ | 5-10% | 意外に完視聴率が高い。YT は TikTok より年齢層が上 | 排除しない。世代依存ネタ (アプリ固有等) を減らすと伸びる |

**成長ループの本体は「女性がパートナーにタグ付け/共有 → 男性が登録 → カップル2人分の視聴者」**。この共有行動を発生させることが全 KPI の上流。

### 2.3 行動パターン: いつ・どこで・どう見られるか

| 行動 | 事実 | 対応 |
| ---- | ---- | ---- |
| 視聴時間帯 | 昼休み (12-13時) と就寝前 (21-23時) の2山。**就寝前が共有行動のピーク** | US ET 夜に投稿。「寝る前にパートナーと見る」文脈に合う穏やかなトーン (docs/03 の毒薄め方針と一致) |
| 視聴環境 | 音あり率が TikTok より高いが、**ミュート視聴も3割** | 字幕焼き込み必須 (既存方針どおり)。音なしでもオチが成立する構成をレビュー基準に追加 |
| Shorts フィード挙動 | スワイプ課金制: 冒頭 1-2 秒で「見た/流した」(Viewed vs Swiped) が判定され、**この比率が初期配信の生死を決める** | §4.1 フック設計 |
| ループ視聴 | 尺を最後まで見て頭に戻ると視聴維持率が 100% を超え、強いシグナルになる | ループ可能なオチ (最後のフレーズが冒頭に繋がる) を月数本仕込む |
| 検索・回遊 | TikTok と違い **YT は検索資産になる** ("couple comedy animation" 等) | タイトルは内部メモではなく検索語を含める (§4.3) |

## 3. ペルソナ (Tier 1 具体化)

> **"Emily" (34, 米オハイオ州コロンバス郊外, 医療事務, 結婚3年目)**
> 21:30、ベッドで Shorts を無限スクロール。夫は隣で別のスマホ。「The Loud Snack」を見て 2 秒でフッと笑い、無言で夫に画面を向ける。夫が「it's you」と言う。Emily は保存し、アカウントをフォローする。翌日、職場の休憩室で同僚に「あのアニメのカップルの動画見た?」と話す。

このペルソナが「画面をパートナーに向ける」までの摩擦を全部取り除くのが本戦略。判断基準に迷ったら「Emily は画面を夫に向けるか?」で決める。

## 4. コンテンツ設計 (YT 最適化)

### 4.1 フック: 最初の 1.5 秒 = Swipe されない画作り

- **1カット目に両キャラ + 状況が一目で分かる構図** (寝室で wife がチップス袋を持っている、等)。説明カット禁止
- 冒頭テキストフックを画面上部 1/3 に大きく: "POV: it's 1am and she's 'being quiet'" 形式。**疑問形 or 当事者形 (you/she/he)** で自分ごと化
- 音: 冒頭に環境音 or 一言目のセリフを 0.5 秒以内に置く (無音の立ち上がりはスワイプされる)

### 4.2 尺と構成: Shorts は「完視聴率 × ループ」ゲーム

| 尺 | 用途 | 備考 |
| -- | ---- | ---- |
| **25-40s (YT 主力)** | Couple Things / Inner Voice | TikTok の 35-55s より**短め**に再編集。YT Shorts は完視聴率の重みが大きく、短尺が有利 |
| 50-60s | 2段オチの上位ネタのみ | 完視聴率 60% を切ったら短尺に戻す |
| 3分 Shorts (2024〜対応) | 使わない | 完視聴率が崩れる。長い企画は §7 の長尺へ |

構成テンプレ: **Hook (0-1.5s) → Setup (〜40%) → Escalation (〜80%) → Punch (〜95%) → ループ接続 or 無言の顔 (最後 1-2s)**。CTA ("follow for more") は入れない — 完視聴率を削るだけで、YT では登録は動画の面白さからしか来ない。

### 4.3 メタデータ (YT 固有の勝ち筋 — TikTok と違う部分)

- **タイトル**: 検索語 + フック。`She Was "Being Quiet" 🍟 | Couple Things #12` 形式 — シリーズ名 + 通し番号で「連続もの」と認識させ、チャネルページからの連続視聴を誘発
- **ハッシュタグ**: `#shorts` + 2-3個まで (`#couplecomedy #relatable #animation`)。それ以上は無意味
- 説明欄: 1行あらすじ + シリーズ再生リストへのリンク
- **再生リスト**: シリーズごとに作成 (Couple Things / Inner Voice / WFH)。Shorts でも回遊と検索面で効く
- 固定コメント: 質問形 ("who's the loud snacker in your house? 👀") — コメント率がシグナルになる + アルゴが会話性を評価

### 4.4 チャネル設計

- チャネル名/ハンドル: `@couplethings_daily` で3チャネル統一 (docs/09 済)
- バナー・アイコン: wife & husband の2ショット。「毎週 月・水・金」と投稿曜日を明記 (登録の理由づけ)
- **投稿頻度: 週5 (Shorts) を12週間固定**。YT のアルゴリズムは一貫性を長期評価する。落とすくらいなら週3に最初から設定する

### 4.5 シリーズ×ターゲットのマトリクス

| シリーズ | 主に取る層 | YT での役割 |
| -------- | ---------- | ----------- |
| Couple Things (週3) | Emily 層 (女性 25-40) | 再生数・共有のエンジン |
| Inner Voice (週1) | 男性 25-40 | **登録転換のエンジン** (この枠だけの固定ファンを作る) |
| Couple WFH (週1) | 25-35 共働き | 平日昼 (休憩時間) 帯に投稿し、時間帯ポートフォリオを分散 |

## 5. アルゴリズム攻略 (Shorts 配信の仕組みに合わせる)

### 5.1 評価シグナルの優先度と対応

1. **Viewed vs Swiped 比率** (冒頭 1-2 秒) → §4.1
2. **平均視聴率 / 完視聴率** → 尺を 25-40s に圧縮、ループ設計
3. **エンゲージ率** (like / comment / share / 登録) → 固定コメントで会話を起こす、シェアされる「うちもこれ」ネタ選定
4. リピート視聴・チャネル回遊 → シリーズ番号 + 再生リスト

### 5.2 初速の設計

Shorts は投稿後の小規模テスト配信 (数百〜数千) の成績で次の配信階層へ進む。初速のテスト母集団を Tier 1 に寄せるため:

- 投稿時刻は **月水金 19:00 ET / 火木 12:00 ET** (publish.yml のスケジュールに反映)
- 投稿直後に伸びなくても**削除しない** (Shorts は数週間後に再配信されることが常態。削除はチャネル評価だけ下げる)
- 同一ネタの再投稿はしない。負けネタは Claude でフック違いに書き直して**別動画として**出す

### 5.3 やってはいけないこと (YT 固有)

- TikTok ロゴ入り動画の流用 (透かし検出でリーチ抑制) → パイプラインは R2 のクリーン原本から各チャネルへ配信する (既存設計どおり、遵守を明文化)
- 30日以内の収益狙いの外部リンク誘導、概要欄のアフィリエイト即設置 (新規チャネルのスパム判定リスク) → docs/12 §8 のゲートどおり Day 30 まで収益施策ゼロ
- 「inauthentic content」判定 (docs/12 §2.2)。**同一テンプレの機械連投が最も危険**。シリーズ内でも構図・展開パターンを最低3型ローテする

## 6. 収益化パス (YT 内の段階)

| 段階 | 条件 (2026-07 目安) | 解放されるもの | 想定時期 (docs/06 準拠) |
| ---- | ------------------- | -------------- | ----------------------- |
| YPP 準会員 | 登録 500 + 直近90日で動画3本 + Shorts 300万再生/90日 or 3,000時間 | Super Thanks / メンバーシップ等のファン課金 | Day 60-90 |
| **YPP 正会員** | 登録 1,000 + **Shorts 1,000万再生/90日** or 4,000時間 | **Shorts 広告収益分配 (45%)** | Day 90-150 |
| 収益安定化 | 月間 300万+ 再生を3ヶ月維持 | RPM 実測に基づく長尺判断 (§7) | Month 6 |

- Shorts 1,000万再生/90日は高い壁 → **正会員へは「4,000時間」側からも狙える**: §7 の長尺コンピレーションを Day 60 から並走させ、どちらか早い方で通す
- ファン課金 (Super Thanks) は preliminary 段階から立つが、期待値は小さい。「収益化バッジが付いたチャネル」という**案件営業上の信用**として使う

### 収益試算 (YPP 通過後)

```
月間 400万再生 (Tier 1 比率 60%) × ブレンド RPM $0.12 = $480/月 (Shorts のみ)
+ 長尺コンピレーション 月30万再生 × RPM $3-6 = $900-1,800/月  ← §7 が本命
```

**Shorts 単体の RPM は構造的に低い。Shorts は「客集め」、長尺が「収益装置」** — これが YT 攻略の核心。

## 7. 発展計画 (Shorts の先)

### Phase Y2: 長尺コンピレーション (Day 60 開始 — 収益の本命)

- 既存 Shorts を 8-12 本束ねた **5-10 分のコンピレーション** ("Couple Things: Episodes 1-10") を週1本投稿
- 追加制作費 ≒ ゼロ (既存素材 + つなぎカット数点 + ffmpeg)。8分以上でミッドロール広告が入り **RPM は Shorts の 20-50 倍**
- 再利用コンテンツポリシー対策: 単純結合ではなく、間にブリッジカット (husband の一言モノローグ等、Higgsfield で 2-3s×数本) と章タイトルを挟み「編集的付加価値」を明確にする
- これが 4,000 時間ルートの弾にもなる (§6)

### Phase Y3: 準長尺オリジナル (Month 6+)

- Inner Voice の 3-5 分版 (1テーマ深掘りモノローグ)、"a week in our apartment" 形式の連作
- Shorts で検証済みの勝ちテーマのみ長尺化する (新規テーマの長尺は打率が低い)

### Phase Y4: 多言語チャネル (Month 6+、docs/12 §2.4)

- `dubbing` でスペイン語チャネルを別チャネルとして開設 (同一チャネル内の多言語混在は登録者体験を壊す)
- 中南米は RPM が低いが、**スペイン語圏 US 視聴者** (RPM は US 水準) が取れるのがポイント

### Phase Y5: コミュニティ資産化 (登録 5万+)

- メンバーシップ (限定ネタ・ボツネタ・制作裏側) / コミュニティ投稿でネタ投票 (次のネタを視聴者に選ばせる = エンゲージ + ネタ供給の両取り)
- docs/12 M4 (グッズ) への導線をチャネルストアで常設

## 8. KPI (docs/06 を YT 用に具体化)

| 指標 | 30日 | 60日 | 90日 |
| ---- | ---- | ---- | ---- |
| 登録者 | 300 | 1,000 | 3,000 |
| Shorts 90日再生 (累計) | 30万 | 150万 | 500万〜1,000万 |
| Viewed vs Swiped | 70%+ | 75%+ | 75%+ |
| 完視聴率 (25-40s) | 60%+ | 70%+ | 75%+ |
| Tier 1 視聴比率 | 40%+ | 50%+ | 60%+ |
| 登録転換 (登録/視聴UU) | — | 0.3%+ | 0.5%+ |

- **Tier 1 視聴比率** が新設 KPI。YT Studio の視聴者地域データを週次レビュー (docs/06) に追加。50% を切ったらネタの文化語彙・投稿時刻を再調整
- 週次レビューは Claude に YT Studio の CSV を渡して「Viewed vs Swiped 下位3本のフック改善案」を出させる (docs/12 §7 と接続)
