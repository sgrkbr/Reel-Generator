# 15. 番組編成と年間スケジュール — Weekly Money Briefing

docs/14 の再考を経た採用ニッチ: **金融 + 経済の週次定点観測** (英語・グローバル・Tier 1 標的は docs/13 のまま)。
コンセプト: _"Your week in money, in 90 seconds."_ — 先週何が起きたか / 今週何が起きるかを、事実ベースで淡々と面白く。

デイリーは追わない (賞味期限24h・労働集約化するため)。**週次を基本周期**とし、月次・四半期・半期・年次の上位サイクルを重ねる。米国経済カレンダーは元々この周期構造なので、番組枠を経済指標の発表リズムに同期させる。

---

## 1. 番組枠 (シリーズ) の定義

| 枠 | 内容 | 尺 / 形式 | 頻度 | 投稿タイミング (ET) |
| -- | ---- | --------- | ---- | ------------------- |
| **Week in Money** (主軸①) | 先週の振り返り: 株・金利・為替・コモディティ・暗号資産で「動いたもの」上位3つと理由 | 60-90s Short | 週1 | **土 09:00** (金曜クローズ後) |
| **The Week Ahead** (主軸②) | 今週のイベント予習: 指標・決算・イベントを重要度順に3つ、「何を見ればいいか」 | 60-90s Short | 週1 | **日 18:00** (週明け前夜) |
| **Money Explained** (フレックス) | evergreen 解説: 「CPIとは何で、なぜ市場が動くのか」等。①②で登場した用語の深掘り | 60-90s Short | 週1 | 水 12:00 |
| **Event Reaction** (臨時) | 大イベント直後の即応: FOMC・CPI サプライズ・急落など。閾値超えの時だけ | 60-90s Short | 月0-3 | イベント当日夜 |
| **Monthly Money Map** | 前月の振り返り + 今月の見どころ。週次の要約ではなく「月のストーリー」として再構成 | **5-8分 長尺** | 月1 | 第1土曜 |
| **Quarterly Review** | 四半期総括: 資産クラス別リターン、テーマ総括、来期の注目 | **10-15分 長尺** | 年4 | 1/4/7/10月 第2土曜 |
| **Half-Year / Year Special** | 半期総括 (7月) / **Year in Review + Year Ahead** (12月末・フラッグシップ) | 15-20分 長尺 | 年2 | §3 参照 |

- ベース週産: Short 3本 (①②+フレックス) ≈ 30 credits/週 + チャートは matplotlib (無料)
- **長尺 (Monthly/Quarterly/Annual) が収益エンジン** (docs/13 §7 のミッドロール戦略をそのまま適用)。週次 Short は長尺への導線 + 登録者の習慣形成装置
- ①②は「毎週土日に必ず出る」ことが最大の価値。**欠番ゼロが唯一の絶対ルール** (定点観測は信頼 = 習慣で成立する)

## 2. 週次サイクルの制作リズム (1週間の流れ)

```
金 16:00 ET 市場クローズ
  → 金夜: データ自動取得 (週間騰落・出来高・ニュース) → Claude が Week in Money 脚本
  → 土 06:00 までに人間レビュー (数字ファクトチェック必須) → 土 09:00 投稿
日 午前: 経済カレンダー自動取得 → The Week Ahead 脚本 → レビュー → 日 18:00 投稿
月-火: 今週の Money Explained ネタ選定 (①②で触れた用語から) → 制作
水 12:00: Money Explained 投稿
木-金: 翌週分の evergreen ストック制作 / 臨時 Event Reaction 待機
```

GitHub Actions cron: 金 21:00 ET (データ取得+脚本ドラフト生成) / 日 10:00 ET (カレンダー取得+脚本) を自動起動し、人間はレビューと承認のみ (docs/07 の半自動原則を維持)。

## 3. 年間スケジュール (米国経済カレンダー同期・毎年再利用可能)

### 3.1 毎月の固定リズム (12ヶ月共通)

| 週 | 固定イベント | 番組対応 |
| -- | ------------ | -------- |
| 第1金曜 | **雇用統計 (NFP)** | 翌日の Week in Money の柱。サプライズ時は Event Reaction |
| 第1土曜 | — | **Monthly Money Map** (前月振り返り + 今月見どころ) |
| 第2-3週 | **CPI (10-15日頃)**、PPI、小売売上高 | Week Ahead で予習 → 結果を Week in Money で回収。この「予告→回収」ループが連続視聴を作る |
| 月末 | **PCE デフレータ** (FRB の本命指標)、消費者信頼感 | Week in Money の材料 |
| 年8回 | **FOMC** (§3.2 参照) | Week Ahead で最重要扱い + 当日 Event Reaction |

### 3.2 月別の年間カレンダー

| 月 | 大型イベント | 特別編成 |
| -- | ------------ | -------- |
| **1月** | Q4 決算開幕 (中旬: 大手銀行→月末: ビッグテック)、FOMC (下旬)、ダボス会議 | **Year Ahead Special** (年始) / Quarterly Review (第2土曜: 前年Q4総括) |
| **2月** | 決算ピーク、FRB 議会証言 (半期金融政策報告) | — |
| **3月** | **FOMC + 経済見通し (SEP/ドットチャート)**、クアドラプル・ウィッチング、四半期末 | 決算シーズン総括回 (Money Explained 拡張) |
| **4月** | **Q1 GDP 速報**、Q1 決算開幕、米確定申告期限 (4/15)、IMF/世銀春季会合 | Quarterly Review (Q1) / 税金ネタの evergreen 強化週間 |
| **5月** | FOMC、決算ピーク、バークシャー株主総会 | "Sell in May" 等の季節性アノマリー検証回 |
| **6月** | **FOMC + SEP**、クアドラプル・ウィッチング、半期末 | — |
| **7月** | **Q2 GDP 速報**、Q2 決算開幕、FOMC | **Half-Year Review** (15分長尺・第1週) / Quarterly Review (Q2) |
| **8月** | **ジャクソンホール会議** (下旬・金融政策の転換点になりやすい)、決算終盤 | 夏枯れ相場ネタ + evergreen ストック増産期間 (イベント閑散期) |
| **9月** | **FOMC + SEP**、クアドラプル・ウィッチング、四半期末 | 「9月は最弱月」アノマリー回 (毎年使える) |
| **10月** | **Q3 GDP 速報**、Q3 決算開幕、暗黒の木曜日/ブラックマンデー記念日 | Quarterly Review (Q3) / 歴史的暴落シリーズ (evergreen・毎年10月に再配置) |
| **11月** | FOMC、決算ピーク、ホリデー商戦開始 (ブラックフライデー)、(偶数年: 米選挙) | ホリデー商戦プレビュー回 |
| **12月** | **FOMC + SEP**、クアドラプル・ウィッチング、年末 | **Year in Review + Year Ahead** (20分フラッグシップ・最終週) — 年間最大の収益コンテンツ |

### 3.3 サイクルの入れ子構造 (まとめ)

```
週次:   Week in Money (土) + The Week Ahead (日) + Money Explained (水)
月次:   Monthly Money Map (第1土曜) ← 雇用統計・CPI・PCE・FOMC を月のストーリーに束ねる
四半期: Quarterly Review (1/4/7/10月) ← GDP + 決算シーズン + FOMC(SEP) が自然に節目を作る
半期:   Half-Year Review (7月) + FRB 議会証言 (2月/7月)
年次:   Year Ahead (1月) + Year in Review (12月) ← フラッグシップ
```

上位サイクルの長尺は**下位サイクルの Short を素材として再構成**する (脚本・チャートを流用、追加コストは TTS とブリッジ画像のみ)。週次を回していれば月次・四半期・年次は「ほぼ無料で」積み上がる — これが本編成の収益設計の核。

## 4. なぜこの編成が強いか (収益との接続)

1. **習慣視聴 = 登録の理由が構造的にある**: 「毎週土日に必ず出る定点観測」は単発バズ依存から脱却できる。docs/13 §4.4 の一貫性評価とも合致
2. **予告→回収ループ**: Week Ahead で「水曜の CPI に注目」→ Week in Money で「結果こうなった」— 視聴者を週2回戻らせる内部導線
3. **長尺がカレンダーから自動発生**: 月次/四半期/年次レビューはネタ出し不要で、金融 RPM ($8-25) のミッドロール収益を定期発生させる
4. **evergreen 在庫と時事の両立**: Money Explained は半永久に回り、8月の閑散期に増産して繁忙期に備えるという在庫運用ができる
5. **毎年再利用可能**: このカレンダー自体が固定資産。2年目以降は「去年の Year in Review」がアーカイブ価値を持つ

## 5. 実装要件 (既存パイプラインへの追加分)

| 追加要素 | 実装 |
| -------- | ---- |
| 市場データ取得 | yfinance (無料) — 週間騰落、指数・金利・為替・BTC。金曜クローズ後に Actions で取得 |
| 経済カレンダー取得 | FRED API (無料) + 決算カレンダー。Week Ahead の材料 |
| チャート生成 | matplotlib で統一スタイルのチャート画像 (Higgsfield 不要・無料)。ブランドカラー・フォント固定 |
| 脚本生成 | Claude: データ+ニュース → 90秒脚本 (数字は取得データのみ使用、生成禁止をプロンプトで強制) |
| **数字ファクトチェック** | レビュー必須項目に追加: 脚本中の全数値がソースデータと一致するか diff 表示する検証スクリプト |
| 免責表示 | 全動画に "Not financial advice. For information only." を定型で焼き込み + 概要欄。投資助言と誤認されない表現ルール (「buy/sell を推奨する文言禁止」) を channels.yaml に明文化 |
| AIGC ラベル | docs/12 §2.2 のとおり自動付与 |
