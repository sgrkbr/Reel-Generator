# 06. KPI と改善サイクル

## 北極星指標

- **TikTok 平均再生数** (直近10本の中央値)
- **フォロワー転換率** = 新規フォロー / 視聴UU

## 補助指標

| 指標 | 目標 (90日) | 取得元 |
| ---- | ----------- | ------ |
| 3秒視聴維持率 | 70%+ | TikTok アナリティクス |
| 完視聴率 | 35%+ | TikTok |
| いいね率 | 5%+ | 各プラットフォーム |
| 保存率 | 1%+ | TikTok / IG |
| シェア率 | 1%+ | 全プラットフォーム |

## マイルストーン (目安)

| 経過 | フォロワー目標 (TikTok) | 平均再生 |
| ---- | ---------------------- | -------- |
| 30日 | 1,000 | 5,000 |
| 60日 | 5,000 | 20,000 |
| 90日 | 10,000 | 50,000 |

## 週次レビュー手順

1. 各チャネルの直近7日分の数値をスプレッドシートに転記
2. 上位3本 / 下位3本を選び、差分 (フック / 尺 / テーマ / 字幕) を比較
3. 学びを `docs/02-pattern-analysis.md` の共通バズ要素チェックリストに追記
4. 翌週のネタリストを更新

## A/B テストの回し方

- 同じネタを2バリエーション (フック違い / 尺違い) で作り、TikTok に時差で投稿
- 1週間後、再生数 / 維持率を比較し、勝ちパターンを採用
- 月1回はシリーズ枠そのものの当たり外れも見直す
