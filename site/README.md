# CoupleThings — public site

Static site hosted at `https://sgrkbr.github.io/CoupleThings/` via GitHub Pages.

## Purpose

- Brand landing page
- Privacy Policy and Terms of Service required for TikTok/Meta/YouTube developer app submission
- Hosts the TikTok URL prefix verification file once issued

## Files

- `index.html` — brand landing page
- `privacy.html` — privacy policy (TikTok compliance)
- `terms.html` — terms of service

## Deployment

Files are mirrored to the `gh-pages` branch at repo root and served by GitHub Pages.

To enable in the repo:
1. Settings → Pages
2. Source: `Deploy from a branch`
3. Branch: `gh-pages`, folder: `/ (root)`
4. Save

To update the site: edit files here, then mirror `site/*` to the `gh-pages` branch.
